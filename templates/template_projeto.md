# Template de Projeto

> Copie este arquivo para a subpasta correta dentro de `projetos/`, renomeie para `nome-do-projeto.md` (e crie também `nome-do-projeto.en.md` para a versão em inglês), e preencha cada seção. Não deixe seções em branco — se não houver informação, escreva explicitamente "Evidência insuficiente" ou "A validar".

```markdown
# Nome do Projeto

## Visão geral
(1-2 parágrafos resumindo o que é o projeto e por que ele importa)

## Problema resolvido
(Qual necessidade de negócio ou operacional motivou este trabalho)

## Contexto
(Em que situação/momento o projeto surgiu)

## Minha atuação
(Lista do que você especificamente fez — não o que a equipe fez)

## Tecnologias utilizadas
(Lista objetiva, sem floreios)

## Solução implementada
(Como o problema foi resolvido, de forma clara para público técnico e não técnico)

## Processo técnico
(Diagrama em texto ou passo a passo resumido)

## Desafios e decisões
(O que foi difícil e por que você escolheu o caminho que escolheu)

## Impacto e métricas
(Tabela: métrica | valor | classificação [comprovada/fornecida/estimada/a validar])

## Competências demonstradas
(Lista de competências técnicas específicas, amarradas a evidência)

## Soft skills demonstradas
(Lista de comportamentos observáveis no projeto, não afirmações genéricas)

## Pontos de melhoria e aprendizados
(Honestidade: o que ficaria melhor, o que você aprenderia fazendo de novo)

## Confidencialidade e anonimização
(O que foi removido/anonimizado e por quê)

## Evidências disponíveis
(Onde a evidência está, sem reproduzir dados sensíveis)

## Status de publicação
(publicável / publicável após anonimização / somente uso interno / precisa de validação)
```

## Checklist antes de publicar um novo projeto

- [ ] Nenhum nome de cliente foi incluído (a menos que você tenha autorizado explicitamente esse caso específico).
- [ ] Nenhuma credencial, senha, token ou string de conexão está presente.
- [ ] Nenhum dado real de produção (CPF, endereço, telefone, valor financeiro) foi reproduzido.
- [ ] Toda métrica está classificada corretamente (comprovada / fornecida / estimada / a validar).
- [ ] O arquivo em inglês (`.en.md`) foi criado ou atualizado junto com o em português.
- [ ] O projeto foi adicionado à tabela em `projetos/README.md`.
