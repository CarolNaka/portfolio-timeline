# Template de Nova Experiência / Atualização de Perfil

Use este template quando uma nova experiência profissional (não necessariamente um projeto técnico detalhado) precisar ser incorporada ao `perfil_profissional.md` ou à `matriz_de_competencias.md`.

## Para adicionar ao perfil profissional

```markdown
### [Nome curto da experiência]
- O que foi: (1 frase)
- Tecnologias envolvidas: (lista)
- Por que é relevante: (1-2 frases conectando com especialidades já existentes ou abrindo uma nova)
```

## Para atualizar a matriz de competências

Se a nova experiência traz evidência nova para uma competência já existente, adicione a evidência ao campo correspondente e reavalie a nota, se necessário, justificando a mudança.

Se a nova experiência introduz uma competência ainda não mapeada, adicione uma nova linha/seção seguindo o mesmo formato das demais:

```markdown
## [Nome da nova competência]

- **Nota: X**
- **Evidências:** ...
- **Projetos relacionados:** ...
- **Justificativa:** ...
- **Lacunas:** ...
- **Sugestão de evolução:** ...
```

## Regras ao preencher

- Nunca atribua nota sem evidência correspondente.
- Se não houver evidência suficiente, escreva literalmente: "Evidência insuficiente para avaliação conclusiva".
- Sempre diferencie fato comprovado, estimativa e informação fornecida por você mesma.
