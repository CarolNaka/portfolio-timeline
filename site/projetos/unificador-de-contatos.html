Unificador de Contatos

Python Selenium Tkinter PyInstaller

Visão geral

Ferramenta própria em Python, com automação via Selenium e interface em Tkinter, distribuída como executável para consultores em campo. Identifica e unifica contatos duplicados direto na base do Legal One, usando a função nativa de unificação — com muito mais autonomia do que o processo tradicional. Ideia e autoria própria.

Problema resolvido

Bases de clientes migradas acumulam contatos duplicados. Corrigir isso pelo processo tradicional exigia: extrair a base de produção, levá-la para homologação, tratar os dados fora do ambiente do cliente, aguardar SLA de liberação, e só então aplicar a correção de volta em produção — um ciclo longo, dependente do time de migração.

Contexto

A ferramenta nasceu para resolver exatamente esse gargalo: permitir que o próprio consultor, sem depender do time de migração, identifique e unifique contatos duplicados agindo diretamente sobre a base do cliente, usando os recursos nativos do Legal One.

Minha atuação

  • Identifiquei o problema e concebi a solução (ideia autoral).
  • Prototipei com pyautogui (coordenadas de tela) — validou a ideia, mas era frágil.
  • Evoluí para Selenium, localizando elementos reais da interface, resiliente a mudanças de layout.
  • Construí interface gráfica própria (Tkinter) e empacotei em executável único (PyInstaller).
  • Gerei log colorido por status e produzi material de treinamento para outros consultores.

Tecnologias utilizadas

Python Selenium WebDriver Tkinter openpyxl / pandas PyInstaller pyautogui (protótipo anterior)

Solução implementada

  1. Login manual e carregamento da base — login manual no navegador controlado pela aplicação (nenhuma credencial armazenada no código).
  2. Identificação de duplicidade — agrupamento de contatos por CPF/CNPJ.
  3. Unificação automatizada — aciona a função nativa "Unificar Contatos" do Legal One via Selenium, para cada grupo de duplicados. Gera relatório Excel colorido ao final.

Processo técnico

Planilha de contatos do cliente
  └─> Login manual no navegador controlado pela ferramenta
       └─> Agrupamento de contatos duplicados por CPF/CNPJ
            └─> Para cada grupo: aciona função nativa "Unificar Contatos" via Selenium
                 └─> Log de execução em Excel (colorido por status)

Desafios e decisões

  • Fragilidade da primeira versão: a automação por coordenadas quebrava com mudança de resolução — reescrita com Selenium resolveu de raiz.
  • Segurança de credenciais: login manual do consultor, em vez de senha armazenada no código.
  • Usabilidade para público não técnico: interface simples e executável único, sem suporte técnico constante.
  • Honestidade técnica: não é a solução mais sofisticada em arquitetura (automação de interface, não API), mas foi a correta para o problema real.

Overview

A tool I built in Python, with Selenium browser automation and a Tkinter interface, distributed as an executable to field consultants. It identifies and merges duplicate contacts directly in the Legal One database, using the system's native merge function — with far more autonomy than the traditional process. Original idea and solution.

Problem solved

Migrated client databases accumulate duplicate contacts. Fixing this through the traditional process required extracting the production database, moving it to staging, treating the data outside the client's live environment, waiting for SLA release, and only then applying the fix back to production.

Context

The tool was built specifically to solve this bottleneck: letting the consultant act directly on the client's database, without depending on the migration team, using Legal One's native features.

My role

  • Identified the problem and conceived the solution (original idea).
  • Prototyped with pyautogui (screen coordinates) — validated the idea, but it was fragile.
  • Evolved to Selenium, locating real interface elements, resilient to layout changes.
  • Built a dedicated graphical interface (Tkinter) and packaged it into a single executable (PyInstaller).
  • Generated a color-coded log and produced training material for other consultants.

Technologies used

Python Selenium WebDriver Tkinter openpyxl / pandas PyInstaller pyautogui (earlier prototype)

Solution implemented

  1. Manual login and data load — manual login in the browser controlled by the application (no credentials stored in code).
  2. Duplicate identification — grouping contacts by tax ID (CPF/CNPJ).
  3. Automated merging — triggers Legal One's native "Merge Contacts" function via Selenium for each duplicate group. Generates a color-coded Excel report at the end.

Technical process

Client contacts spreadsheet
  └─> Manual login in the browser controlled by the tool
       └─> Grouping duplicate contacts by tax ID (CPF/CNPJ)
            └─> For each group: trigger native "Merge Contacts" function via Selenium
                 └─> Excel execution log (color-coded by status)

Challenges and decisions

  • Fragility of the first version: coordinate-based automation broke with resolution changes — rewriting with Selenium fixed this at the root.
  • Credential security: manual consultant login, instead of a stored password in code.
  • Usability for a non-technical audience: simple interface and single executable, without constant technical support.
  • Technical honesty: not the most sophisticated architecture (interface automation, not API), but the right solution for the real problem.
