      Unificador de Contatos

      Ferramenta autoral de saneamento de duplicidade — ideia e implementação próprias

      Contact Deduplication Tool

      Original idea and solution — authored and built independently

      Python Selenium Tkinter PyInstaller

      Visão geral

      Ferramenta própria em Python (Selenium + Tkinter), distribuída como executável para consultores em campo, que identifica e unifica contatos duplicados direto na base do Legal One, usando a função nativa de unificação. Nasceu de um gargalo real: pelo processo tradicional, corrigir duplicidade exigia extrair a base, tratar em homologação, aguardar SLA e reaplicar em produção, sempre dependendo do time de migração. Ideia e autoria próprias.

      Minha atuação

      • Identifiquei o problema e idealizei a solução.
      • Prototipei com pyautogui (coordenadas de tela) e evoluí para Selenium, com seleção direta dos elementos da interface.
      • Criei a interface gráfica (Tkinter) e empacotei em executável único (PyInstaller).
      • Gerei log colorido por status e produzi material de treinamento em vídeo para outros consultores.

      Como funciona

      O consultor faz login manual no navegador controlado pela ferramenta e carrega a planilha. A ferramenta agrupa os duplicados por CPF/CNPJ, aciona a função nativa “Unificar Contatos” de cada grupo e gera um log em Excel.

      Planilha de contatos do cliente
  └─> Login manual no navegador controlado pela ferramenta
       └─> Agrupamento de contatos duplicados por CPF/CNPJ
            └─> Para cada grupo: aciona função nativa "Unificar Contatos" via Selenium
                 └─> Log de execução em Excel (colorido por status)

      Desafios e aprendizados

      • Fragilidade da 1ª versão: a automação por coordenadas quebrava com mudança de resolução; a reescrita com Selenium resolveu.
      • Usabilidade: interface simples e executável único, pensados para quem não é técnico.
      • Pragmatismo: não é a arquitetura mais sofisticada (automação de interface, não API), mas é a solução certa para o problema real.

      Overview

      Own tool built in Python (Selenium + Tkinter), distributed as an executable to field consultants, that identifies and merges duplicate contacts directly in the Legal One database using its native merge function. It came from a real bottleneck: with the traditional process, fixing duplicates meant extracting the database, treating it in staging, waiting for an SLA, and reapplying in production, always depending on the migration team. Original idea and authorship.

      What I did

      • I identified the problem and conceived the solution.
      • I prototyped with pyautogui (screen coordinates) and evolved to Selenium, selecting interface elements directly.
      • I built the graphical interface (Tkinter) and packaged it as a single executable (PyInstaller).
      • I generated a status-colored log and produced training video material for other consultants.

      How it works

      The consultant logs in manually in the browser controlled by the tool and loads the spreadsheet. The tool groups duplicates by tax ID, triggers Legal One's native “Merge Contacts” function for each group, and generates an Excel log.

      Client contacts spreadsheet
  └─> Manual login in the browser controlled by the tool
       └─> Duplicate contacts grouped by tax ID
            └─> For each group: triggers native "Merge Contacts" via Selenium
                 └─> Execution log in Excel (colored by status)

      Challenges and learnings

      • Fragile first version: coordinate-based automation broke when the resolution changed; rewriting with Selenium fixed it at the root.
      • Usability: simple interface and a single executable, designed for non-technical users.
      • Pragmatism: not the most sophisticated architecture (interface automation, not an API), but the right solution for the real problem.
      • Limits and next steps: depends on Legal One's layout; merges by tax ID (could evolve to name similarity); API integration, if available; measuring usage frequency.
