      Visão geral

      Scripts Python criados para tirar tarefas manuais do dia a dia de migração e suporte: importar planilhas para o banco, comparar volumes entre bases, extrair dados de MySQL, consolidar erros e avisos e apoiar a gestão de acessos. Cada um resolve uma necessidade pontual da rotina.

      Minha atuação

      • Importador genérico de Excel para banco: lê todas as abas (ou uma específica) e padroniza os nomes de coluna.
      • Extração de andamentos e compromissos/tarefas de bases MySQL de origem.
      • Comparação de volumetria entre bases, com relatório em Excel.
      • Extração de erros e avisos (Totais, Erros, Avisos) em Excel formatado.
      • Apoio à gestão de acesso de usuários do Legal One.

      Como funciona

      Cada script parte de uma fonte (Excel, MySQL ou SQL Server) e entrega o banco atualizado ou um relatório consolidado. Bibliotecas: pandas, openpyxl, pyodbc, SQLAlchemy e PyMySQL.

      Fonte de dados (Excel, MySQL, SQL Server)
  └─> Script Python específico (importação, extração, comparação ou verificação)
       └─> Banco de destino atualizado OU relatório Excel consolidado

      Overview

      Python scripts built to remove manual tasks from day-to-day migration and support: importing spreadsheets into databases, comparing volumes between databases, extracting MySQL data, consolidating errors and warnings, and supporting access management. Each one solves a specific need of the routine.

      What I did

      • Generic importer from Excel to a database: reads every sheet (or a specific one) and standardizes column names.
      • Extraction of activity logs and appointments/tasks from MySQL source databases.
      • Volume comparison between databases, with an Excel report.
      • Errors-and-warnings extraction (Totals, Errors, Warnings) into a formatted Excel file.
      • Support for Legal One user-access management.

      How it works

      Each script starts from a source (Excel, MySQL, or SQL Server) and delivers an updated database or a consolidated report. Libraries: pandas, openpyxl, pyodbc, SQLAlchemy, and PyMySQL.

      Data source (Excel, MySQL, SQL Server)
  └─> Specific Python script (import, extraction, comparison, or verification)
       └─> Updated target database OR consolidated Excel report
