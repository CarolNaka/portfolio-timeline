Visão geral

Scripts Python para ganho de produtividade em migração e manutenção de dados: importação de CSV/Excel para banco, comparação de volumetria, extração de dados do MySQL e gestão de acesso de usuários.

Problema resolvido

Diversas etapas do processo de migração e suporte (conferir se duas bases têm a mesma quantidade de registros, subir uma planilha inteira para o banco, extrair dados de uma base MySQL, resetar o acesso de um usuário) eram candidatas a automação simples que elimina passos manuais repetitivos.

Contexto

Os scripts foram desenvolvidos como ferramentas de apoio paralelas ao trabalho principal de migração e consultoria, cada um resolvendo uma necessidade pontual identificada na rotina.

Minha atuação

  • Importador genérico e parametrizável de Excel para banco (importa_excel.py).
  • Scripts de extração a partir de bases MySQL de origem (andamentos e compromissos/tarefas).
  • Scripts de comparação de volumetria entre bases, com relatório Excel.
  • Script de reset de acesso de usuários do Legal One via atualização direta em banco.
  • Script de extração de erros e avisos, conectando via pyodbc, consolidando em Excel formatado.

Tecnologias utilizadas

Python pandas openpyxl pyodbc sqlalchemy pymysql

Solução implementada

  • Importador genérico: lê planilha Excel inteira (todas as abas ou uma específica), sanitiza nomes de coluna e insere via sqlalchemy.
  • Extração MySQL: conecta à base de origem e extrai andamentos e compromissos/tarefas.
  • Comparação de volumetria: compara contagem de registros entre bases, apoiando validação pós-tratamento.
  • Extração de erros e avisos: executa scripts SQL de verificação e organiza o resultado em Excel (Totais, Erros, Avisos).
  • Reset de acessos: automatiza reset de acesso diretamente no banco.

Processo técnico

Fonte de dados (Excel, MySQL, SQL Server)
  └─> Script Python específico (importação, extração, comparação ou verificação)
       └─> Banco de destino atualizado OU relatório Excel consolidado

Desafios e decisões

  • Scripts pontuais vs. ferramenta única: priorizou agilidade de entrega para necessidades específicas.
  • Evolução de abordagem: protótipo Duplicidade_auto.py (baseado em pyautogui) evoluiu para a abordagem Selenium do projeto Unificador de Contatos.

Overview

Python scripts for productivity gains in data migration and maintenance: CSV/Excel-to-database import, volume comparison, MySQL data extraction, and user-access management.

Problem solved

Several steps in the migration and support process (checking record counts, uploading a spreadsheet, extracting data from a MySQL database, resetting user access) were good candidates for simple automation removing repetitive manual steps.

Context

The scripts were developed as support tools running alongside the main migration and consulting work, each solving a specific need identified in day-to-day routine.

My role

  • Generic, parameterized Excel-to-database importer (importa_excel.py).
  • Extraction scripts from source MySQL databases (activity logs and appointments/tasks).
  • Database volume-comparison scripts, with Excel reporting.
  • Legal One user-access reset script via direct database update.
  • Error/warning extraction script, connecting via pyodbc, consolidated into formatted Excel.

Technologies used

Python pandas openpyxl pyodbc sqlalchemy pymysql

Solution implemented

  • Generic importer: reads an entire Excel spreadsheet (every sheet or one specified), sanitizes column names, and inserts via sqlalchemy.
  • MySQL extraction: connects to the source database and extracts activity logs and appointments/tasks.
  • Volume comparison: compares record counts between databases, supporting post-treatment validation.
  • Error/warning extraction: runs verification SQL scripts and organizes the result into Excel (Totals, Errors, Warnings).
  • Access reset: automates resetting access directly in the database.

Technical process

Data source (Excel, MySQL, SQL Server)
  └─> Dedicated Python script (import, extraction, comparison, or verification)
       └─> Updated target database OR consolidated Excel report

Challenges and decisions

  • Point scripts vs. a single tool: prioritized delivery speed for specific needs.
  • Approach evolution: the Duplicidade_auto.py prototype (based on pyautogui) later evolved into the Selenium approach used in the Contact Deduplication Tool.
