# Evidências

Este diretório não contém cópias de arquivos-fonte originais (conforme a regra de não copiar arquivos sem autorização). Em vez disso, reúne **referências sanitizadas** — descrições do tipo, nome genérico e localização interna da evidência que sustenta cada afirmação feita nos documentos de projeto.

Para a lista completa de referências, veja [referencias_sanitizadas.md](referencias_sanitizadas.md).

Para os feedbacks internos recebidos (colegas e mentoria técnica), veja [feedbacks_recebidos.md](feedbacks_recebidos.md).

Para o inventário bruto de arquivos analisados (incluindo achados que não geraram projeto dedicado), veja [../inventario_inicial.md](../inventario_inicial.md).
