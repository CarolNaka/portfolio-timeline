## English

### Purpose

This repository documents, technically and based on evidence, the data migration, recurring consulting, and automation projects developed throughout the author's work as a technical consultant for legal case-management systems (Legal One and competing platforms: Astrea, Projuris, CPJ, CP-PRO).

### Portfolio overview

- **[Professional profile](perfil_profissional.en.md)** — summary of specialties, technologies, and differentiators, based on evidence.
- **[Competency matrix](matriz_de_competencias.en.md)** — technical assessment of 18 competencies, split into **technical skills** and **soft skills**, each with a score, evidence, and justification.
- **[Legal One Experience](site/experiencias/legal-one.html)** — projects and metrics for this experience (within the site). Detailed documentation for each project, in priority order:
  1. [Database-to-Database Migration Between Competing Platforms](projetos/migracoes/migracao-banco-a-banco-concorrentes.en.md)
  2. [Recurring Database Consulting](projetos/consultoria_recorrente/consultoria-recorrente-legal-one.en.md)
  3. [Contact Deduplication Tool](projetos/saneamento_contatos/unificador-de-contatos.en.md) — original idea and solution
  4. [Python Productivity Automations](projetos/automacoes_python/automacoes-produtividade-python.en.md) and [SQL/VBA Automations](projetos/automacoes_sql_vba/automacoes-sql-vba.en.md)
- **[Metrics and indicators](metricas/metricas_e_indicadores.en.md)** — evidence-backed, estimated, and pending-validation numbers.
- **[Site](site/index.html)** — home page with about, skills, and a list of experiences; each professional experience (e.g., Legal One) has its own page inside `site/experiencias/`, publishable on GitHub Pages.

### Core technologies and skills

SQL Server (T-SQL) · Python · Selenium · Tkinter · VBA · Git/GitHub · Excel · PowerShell — applied to data migration, recurring consulting, process automation, and data sanitization.

### Viewing locally

- **Markdown:** any Markdown reader, or GitHub itself, renders the `.md` files normally.
- **Site:** open `site/index.html` directly in a browser (no server required — it's a static site with no external dependencies).
